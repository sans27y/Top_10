TOP 10 OST — REACT + TAILWIND CSS + VITE + SUPABASE

TECNOLOGÍAS
- React: interfaz y componentes de las páginas.
- Tailwind CSS: utilidades de estilos; se conserva el CSS original para no alterar el diseño.
- Vite: servidor de desarrollo y compilación.
- Supabase: backend existente (Auth, PostgreSQL y Storage).

REQUISITOS
- Node.js 20.19+ o 22.12+.
- npm.
- Acceso al proyecto Supabase configurado para Top 10 OST.

INSTALACIÓN Y EJECUCIÓN
1. Descomprime el ZIP.
2. Abre la carpeta Top10_OST_Supabase_Completo en Visual Studio Code.
3. Abre la terminal dentro de esa carpeta.
4. Ejecuta: npm install
5. Verifica que exista .env con VITE_SUPABASE_URL y VITE_SUPABASE_ANON_KEY. Si falta, copia .env.example como .env y completa los valores de tu proyecto Supabase usando la clave publishable/anon.
6. Ejecuta: npm run check
7. Ejecuta: npm run dev
8. Abre la URL local que indica Vite.

COMPILACIÓN
- Ejecuta: npm run build
- Vite genera la versión de publicación dentro de dist/.
- Publica el contenido de dist/ en un hosting estático que soporte las rutas HTML del proyecto.

PÁGINAS
- index.html: inicio de sesión.
- registro.html: registro.
- top10.html: ranking de 10 canciones.
- explorar.html: catálogo original y canciones compartidas.
- subir.html: publicación de MP3 y portada.

BACKEND SUPABASE
- Auth: registro e inicio de sesión.
- PostgreSQL: canciones_publicadas, calificaciones y comentarios.
- Storage: buckets canciones y portadas.
- Se mantienen las operaciones existentes de calificar, comentar, publicar y consultar canciones.
- MIGRACION_SUPABASE.sql contiene la configuración completa e idempotente para las tablas, RLS, buckets y políticas de almacenamiento. Ejecútalo en Supabase > SQL Editor si aún no está aplicada.
- Las cuentas usan nombre de usuario como identificador de acceso y un correo interno terminado en .invalid. En Supabase Auth, desactiva la confirmación por correo para este flujo de registro con nombre de usuario; no se puede recibir un correo enviado a ese dominio.
- No utilices nunca la clave service_role/secret en el frontend. La clave publishable/anon está diseñada para el cliente y debe estar protegida por RLS.

AUDIO ORIGINAL
El ZIP de origen no contenía los diez archivos MP3 locales. Para activar la reproducción de las canciones originales, agrega los archivos autorizados en public/sonidos/ con los nombres exactos indicados en public/sonidos/README.txt. Las canciones subidas por la comunidad se almacenan en Supabase Storage y no dependen de esa carpeta.

ALMACENAMIENTO DE SESIÓN
La aplicación no implementa almacenamiento propio de sesión en localStorage. Supabase Auth mantiene la sesión del cliente mediante su mecanismo persistente predeterminado del SDK; esto es parte del funcionamiento de Supabase Auth.

NOTAS DE VALIDACIÓN
- npm run check revisa la estructura del proyecto, dependencias declaradas, configuración y sintaxis de los scripts JavaScript clásicos.
- npm run build valida la compilación de React/Vite; debe ejecutarse después de npm install.
- Para probar el flujo completo, verifica además las políticas y los buckets en tu propio proyecto Supabase, crea una cuenta de prueba y realiza una publicación, calificación y comentario.
